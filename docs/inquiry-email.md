# Avalon Labs inquiry email

The site links to `inquiries@avalonlabs.ai`. Resend receives mail for the domain,
then sends an `email.received` webhook to:

`https://www.avalonlabs.ai/api/webhooks/resend`

The handler forwards only mail addressed to `inquiries@avalonlabs.ai` to
`kyle@banedigital.com`. It preserves the subject, body, and attachments and sets
Reply-To to the original reply address or sender. It does not send an autoresponse.

## Production configuration

1. Add `avalonlabs.ai` to the Bane Digital Resend account with sending and receiving enabled.
2. Add the exact DNS records generated by Resend and verify both capabilities.
3. Set `RESEND_API_KEY` in the Vercel project's Production environment. Receiving
   requires a key with Full access; a sending-only key cannot retrieve inbound mail.
4. Create a Resend webhook for `email.received` at the URL above. Set its signing
   secret as `RESEND_WEBHOOK_SECRET` in the same Vercel environment.
5. Deploy the site after setting both secrets. Never commit their values.
6. Send a test message to the inquiry address, confirm delivery in Kyle's inbox,
   and check that Reply targets the original sender.

The handler validates the webhook signature before making API calls and checks
both the event recipient and stored recipient. Other recipients are ignored.
Transient failures return HTTP 502 so Resend can retry. Missing configuration
returns HTTP 503. Resend's idempotency key prevents duplicate forwards within its
24-hour deduplication window; manually replaying events after that can resend mail.
Attachment and message sizes remain subject to Resend's sending limits.

Run the focused checks with `pnpm exec tsx --test tests/inquiry-email.test.ts`,
then `pnpm exec tsc --noEmit` and `pnpm build`.
